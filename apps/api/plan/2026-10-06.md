# Ledgerly API Plan - 2026-10-06

## Goal

Move Ledgerly from a backend where clients can identify users through request data to one where the server can authenticate users and establish their identity securely.

Add the first authentication and authorization layer using password hashing, JWT access tokens, authentication guards, and authenticated account ownership.

By the end of this phase, a user should be able to register, log in, receive an access token, retrieve their own identity, and interact only with accounts that belong to them.
